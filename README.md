## サービス概要
「ゲームを長時間やってしまう」、「ゲーム仲間に上手く切り出せない」を解決するアプリです。

## このサービスへの思い・作りたい理由
自分がよくゲームをしていた時期に、『夢中になってなかなかやめようと思えない』、『一緒にプレイしているゲーム仲間へ「やめます」と言いづらい』といった問題が発生していた。<br>
この問題が解決しやすくなれば、時間管理がスムーズに行きやすくなると考えた。

## ユーザー層について
「楽しむときは楽しむ。やるべきことはしっかりやる。」という習慣を身に付け、時間を有効活用することの手助けとなるアプリを作りたいと思ったから。

## サービスの利用イメージ
ゲームを切り上げたいときの心理的障壁が減り、自分の思うように時間管理ができるようになる。
### <心理的障壁を減らすための工夫>
- ゲームの終了予定時刻に対して何分オーバー（アンダー）でやめることができたかを統計データで可視化することで、達成感を得られる。  
- 定型文機能により、ゲーム仲間にやめることをどう切り出せばいいかをその都度考える必要がなくなる。<br>
そのため、「どう伝えるか考えなければ…」と思う必要がなく、「この場合であれば、こんな感じで言おう」とスムーズに考えることができる。

## ユーザーの獲得について
- 友人に使ってもらう。  
- XやMattermostなどで公開して、使ってもらう。

## サービスの差別化ポイント・推しポイント
ゲーム仲間にゲームを途中でやめることを伝える時の心理的障壁を減らすための工夫がある。

## 機能候補
### <MVPリリースまで>
- ユーザ登録・ログイン機能
- アラーム機能
- アラーム記録作成機能（何分オーバー or アンダーでプレイを終了できたか記録）
- 定型文一覧機能(デフォルトのみ)
#### <デフォルトの定型文の例(理由別)>
<予定が急に入った場合>
- 「申し訳ありません、急用が入ってしまったので今日はここで失礼します。」  
- 「急な用事ができちゃったので今日はここで抜けますね、ごめんね。」

<ゲームの進行が悪くて気まずくなった場合>
- 「ごめん、今日はちょっと調子悪いので抜けます！また次回リベンジさせて…！」  
- 「集中できなくなってきたので、今日はここで抜けます！」

### <本リリースまで>
- アラームの記録のグラフ化
- 定型文のブックマーク機能
- 定型文作成機能
- ゲーム日記機能
- ユーザー検索機能（フレンド登録のため）
- フレンド機能
- アラームグループ機能（ゲーム仲間とアラームを共有する機能）

## 使用する技術スタック

- グラフ：Chart.js
- データベース：PostgreSQL
- デプロイ先：Render
