#### アプリURL： https://game-exit.onrender.com
## サービス概要
「ゲームを長時間やってしまう」、「ゲーム仲間に上手く切り出せない」といった問題を解決するアプリです。

## サービスの利用イメージ
ゲームを切り上げたいときの心理的障壁が減り、自分の思うように時間管理ができるようになる。
### <心理的障壁を減らすための工夫>
- ゲームの終了予定時刻に対して何分オーバーorアンダーでやめることができたかを統計データで可視化することで、達成感を得られる。  
- 定型文機能により、ゲーム仲間にやめることをどう切り出せばいいかをその都度考える必要がなくなる。<br>
そのため、「どう伝えるか考えなければ…」と思う必要がなく、「この場合であれば、こんな感じで言おう」とスムーズに考えることができる。

## ユーザー層について
「楽しむときは楽しむ。しかし、やるべきことはしっかりやる。」という習慣を身に付け、より充実したゲームライフを送りたいという方向けに作っています。

## このサービスへの思い・作りたい理由
自分がよくゲームをしていた時期に、『夢中になってなかなかやめようと思えない』、『一緒にプレイしているゲーム仲間へ「やめます」と言いづらい』といった問題が発生していました。<br>
この問題が解決できれば、時間管理がスムーズに行きやすくなると考え、このアプリを考案しました。

## 機能候補
### <本リリースまで>
- 定型文作成機能
- 定型文のブックマーク機能
- 定型文検索機能
- 記録のSNSシェア機能
- スマホ対応
- ユーザー検索機能（フレンド登録のため）
- フレンド機能
- アラームグループ機能（ゲーム仲間とアラームを共有する機能）

## 使用する技術スタック
- バックエンド：Ruby on Rails  
- アラーム通知：GoodJob、Resend
- データベース：PostgreSQL
- デプロイ先：Render
